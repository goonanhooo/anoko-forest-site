Mesh and original facial atlas sourced from the publicly distributed
ChiikawaValuables v2.0.0 package by Dumbapple:
https://thunderstore.io/c/repo/p/Dumbapple/ChiikawaValuables/v/2.0.0/
That package credits the three character models to Nini.

Changes: file conversion to GLB, coordinate convention, uniform scale,
disconnected-part pivots for animation; reactive facial texture variants.
The packaged GLB files retain the source geometry. Runtime subdivision smooths
the imported parts, and body proportions, Hachiware blue and facial glyphs are
adjusted to the user-supplied figure photographs. UV seams remain in place.
The supplied photographs are included only as references for this personal Site.
